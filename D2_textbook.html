D2: データの絞り込みとソート

Oracle Database SQL (1Z0-071) 対策
WHERE 句を使ったデータの絞り込みと、ORDER BY を使ったデータのソート方法を学びます。

略称・用語定義
略称 正式名称 意味

DESC Descending（デセンディング） 降順。大きい値から小さい値の順に並べる。ORDER BY に明示的に指定する

WHERE句と比較演算子
WHEREBETWEENIN比較演算子ANDORNOT

WHERE 句の基本

WHERE 句を使うと条件に合う行だけを取得できます。

SELECT LAST_NAME, SALARY
FROM   EMPLOYEES
WHERE  SALARY >= 10000;
-- 実行結果例：
-- LAST_NAME   SALARY
-- ----------  ------
-- King         24000
-- Kochhar      17000
-- De Haan      17000
-- （SALARY が 10000 以上の行のみ返される）

比較演算子一覧

演算子意味例
=等しいSALARY = 5000
<> または !=等しくないSALARY <> 5000
>より大きいSALARY > 5000
<より小さいSALARY < 5000
>=以上SALARY >= 5000
<=以下SALARY <= 5000

BETWEEN ... AND

-- 5000 以上 10000 以下の給与（両端含む）
SELECT LAST_NAME, SALARY
FROM   EMPLOYEES
WHERE  SALARY BETWEEN 5000 AND 10000;
-- 実行結果例：
-- LAST_NAME   SALARY
-- ----------  ------
-- Hunold        9000
-- Ernst         6000
-- Austin        4800
-- （SALARY = 5000 および 10000 の行も含まれる）

IN 演算子

-- 部署 10, 20, 30 のいずれか
SELECT LAST_NAME, DEPARTMENT_ID
FROM   EMPLOYEES
WHERE  DEPARTMENT_ID IN (10, 20, 30);
-- 実行結果例：
-- LAST_NAME   DEPARTMENT_ID
-- ----------  -------------
-- Whalen                 10
-- Hartstein              20
-- Fay                    20
-- Raphaely               30
-- （部署 10, 20, 30 のいずれかに属する行が返される）

AND / OR / NOT

-- AND: 両方の条件を満たす
SELECT LAST_NAME, SALARY, DEPARTMENT_ID
FROM   EMPLOYEES
WHERE  SALARY > 5000
AND    DEPARTMENT_ID = 50;
-- 実行結果例：
-- LAST_NAME   SALARY  DEPARTMENT_ID
-- ----------  ------  -------------
-- Mourgos       5800             50
-- Rajs          3500             50
-- （SALARY > 5000 かつ DEPARTMENT_ID = 50 の行のみ返される）

-- OR: どちらかの条件を満たす
SELECT LAST_NAME, SALARY, DEPARTMENT_ID
FROM   EMPLOYEES
WHERE  SALARY > 10000
OR     DEPARTMENT_ID = 10;
-- 実行結果例：
-- LAST_NAME   SALARY  DEPARTMENT_ID
-- ----------  ------  -------------
-- King         24000             90
-- Kochhar      17000             90
-- Whalen        4400             10
-- （SALARY > 10000 または DEPARTMENT_ID = 10 のどちらかを満たす行が返される）
試験のポイント： BETWEEN の値は「小さい値 AND 大きい値」の順で指定します。NOT IN に NULL が含まれる場合、全件が返りません（NULL との比較が不定のため）。AND は OR より優先度が高いため、OR を使う場合は括弧で明示的にグループ化を推奨。
練習問題
問題 1 #OSLV-D2-001

以下のSQL文で返される行を正しく説明しているものはどれか。
```sql
SELECT employee_id, salary
FROM employees
WHERE salary BETWEEN 5000 AND 10000;
```

  • A. salary が 5000 より大きく 10000 より小さい行
  • B. salary が 5000 以上かつ 10000 以下の行
  • C. salary が 5000 未満または 10000 超の行
  • D. salary が 5000 または 10000 の行のみ
解答・解説を見る

正解: B. salary が 5000 以上かつ 10000 以下の行

正解は「salary が 5000 以上かつ 10000 以下の行」である。BETWEEN x AND y は x <= 値 <= y の範囲を意味し、両端の値を含む（inclusive）。したがって salary = 5000 および salary = 10000 の行も結果に含まれる。選択肢Aは両端を含まない（exclusive）の説明であり誤り。BETWEENはNOT BETWEENで否定でき、数値・日付・文字列のいずれにも使用可能。Oracle SQL Reference §BETWEEN条件参照。

問題 2 #OSLV-D2-002

以下のSQL文の結果として正しいものはどれか。
```sql
SELECT last_name
FROM employees
WHERE last_name LIKE '_a%';
```

  • A. 'a' を含む全ての last_name
  • B. 'a' で始まる last_name
  • C. 2文字目が 'a' の last_name を持つ全行
  • D. 'a' で終わる last_name
解答・解説を見る

正解: C. 2文字目が 'a' の last_name を持つ全行

正解は「2文字目が 'a' の last_name を持つ全行」である。LIKEパターンの_（アンダースコア）は任意の1文字に一致し、%（パーセント）は0文字以上の任意の文字列に一致する。'_a%' は「1文字（何でもよい）」+「a」+「0文字以上（何でもよい）」のパターンであるため、2文字目が 'a' である文字列に一致する。例: 'James', 'Mary', 'Barry' 等。Oracle SQL Reference §LIKE条件参照。

問題 3 #OSLV-D2-003

以下のSQL文の実行結果として正しいものはどれか。
```sql
SELECT last_name, salary
FROM employees
WHERE commission_pct IS NULL
ORDER BY salary DESC NULLS LAST;
```
commission_pctがNULLの行には salary = 8000, 5000, NULL の3行があるとする。

  • A. salary: NULL → 8000 → 5000 の順で3行
  • B. salary: 8000 → 5000 → NULL の順で3行
  • C. salary: 5000 → 8000 → NULL の順で3行
  • D. エラーになる（NULLをORDER BYに使えない）
解答・解説を見る

正解: B. salary: 8000 → 5000 → NULL の順で3行

正解は「salary: 8000 → 5000 → NULL の順で3行」である。ORDER BY salary DESC はsalaryを降順にソートする。NULLS LAST を指定すると、NULLの値を持つ行はソート結果の末尾に配置される。IS NULLはNULL値を持つ行を選択する正しい構文（= NULLは使えない）。ORDER BYのデフォルトNULL順序は昇順（ASC）ではNULLS LAST、降順（DESC）ではNULLS FIRSTとなる。NULLS FIRST/NULLS LASTで明示的に制御できる。

LIKE演算子とワイルドカード
LIKEワイルドカードアンダースコアパーセントESCAPE

LIKE 演算子

LIKE は文字列のパターンマッチングに使います。2種類のワイルドカードがあります。

ワイルドカード意味例
%（パーセント）0文字以上の任意の文字列'A%' → A で始まる
_（アンダースコア）任意の1文字'_a%' → 2文字目が a
-- 'S' で始まる名前
SELECT LAST_NAME
FROM   EMPLOYEES
WHERE  LAST_NAME LIKE 'S%';
-- 実行結果例：
-- LAST_NAME
-- ----------
-- Sully
-- Smith
-- （'S' で始まる姓の行が返される）

-- 2文字目が 'a' の名前
SELECT LAST_NAME
FROM   EMPLOYEES
WHERE  LAST_NAME LIKE '_a%';
-- 実行結果例：
-- LAST_NAME
-- ----------
-- Fay
-- Hall
-- （2文字目が 'a' の姓の行が返される）

-- 名前に 'an' を含む
SELECT LAST_NAME
FROM   EMPLOYEES
WHERE  LAST_NAME LIKE '%an%';
-- 実行結果例：
-- LAST_NAME
-- ----------
-- Grant
-- Landry
-- （'an' を含む姓の行が返される）

ESCAPE オプション

% や _ を文字として検索したい場合は ESCAPE を使います。

-- JOB_ID に 'SA_' を含む（_ をリテラルとして扱う）
SELECT JOB_ID
FROM   EMPLOYEES
WHERE  JOB_ID LIKE '%SA$_%' ESCAPE '$';
-- 実行結果例：
-- JOB_ID
-- --------
-- SA_MAN
-- SA_REP
-- （'SA_' を文字列として含む JOB_ID の行が返される）
試験のポイント： LIKE の比較は大文字小文字を区別します（Oracle のデフォルト）。ESCAPE に使う文字は任意の1文字で、慣例的に \ や $ が使われます。

ORDER BY句
ORDER BYASCDESCNULLS FIRSTNULLS LAST

ORDER BY の基本

ORDER BY 句で検索結果をソートします。デフォルトは昇順（ASC）です。

-- 給与の昇順（デフォルト）
SELECT LAST_NAME, SALARY
FROM   EMPLOYEES
ORDER BY SALARY;
-- 実行結果例：
-- LAST_NAME   SALARY
-- ----------  ------
-- Olson         2100
-- Markle        2200
-- Philtanker    2200
-- （SALARY の小さい順に並ぶ）

-- 給与の降順
SELECT LAST_NAME, SALARY
FROM   EMPLOYEES
ORDER BY SALARY DESC;
-- 実行結果例：
-- LAST_NAME   SALARY
-- ----------  ------
-- King         24000
-- Kochhar      17000
-- De Haan      17000
-- （SALARY の大きい順に並ぶ）

-- 複数列でのソート（部署昇順、給与降順）
SELECT LAST_NAME, DEPARTMENT_ID, SALARY
FROM   EMPLOYEES
ORDER BY DEPARTMENT_ID ASC, SALARY DESC;
-- 実行結果例：
-- LAST_NAME   DEPARTMENT_ID  SALARY
-- ----------  -------------  ------
-- Whalen                 10    4400
-- Hartstein              20   13000
-- Fay                    20    6000
-- （部署番号の昇順、同一部署内では給与の降順に並ぶ）

NULLS FIRST / NULLS LAST

-- NULL を最初に表示
SELECT LAST_NAME, COMMISSION_PCT
FROM   EMPLOYEES
ORDER BY COMMISSION_PCT NULLS FIRST;
-- 実行結果例：
-- LAST_NAME   COMMISSION_PCT
-- ----------  --------------
-- King                （NULL）
-- Kochhar             （NULL）
-- Abel                   0.30
-- （NULL の行が先頭に来る）

-- NULL を最後に表示
SELECT LAST_NAME, COMMISSION_PCT
FROM   EMPLOYEES
ORDER BY COMMISSION_PCT NULLS LAST;
-- 実行結果例：
-- LAST_NAME   COMMISSION_PCT
-- ----------  --------------
-- Grant                  0.15
-- Abel                   0.30
-- King                （NULL）
-- （NULL の行が末尾に来る）

列位置や別名でのソート

-- SELECT の列番号でソート（2列目 = SALARY）
SELECT LAST_NAME, SALARY
FROM   EMPLOYEES
ORDER BY 2 DESC;
-- 実行結果例：
-- LAST_NAME   SALARY
-- ----------  ------
-- King         24000
-- Kochhar      17000
-- De Haan      17000
-- （SELECT リストの2列目 SALARY の降順で並ぶ）

-- 列別名でソート
SELECT LAST_NAME, SALARY * 12 AS annual_sal
FROM   EMPLOYEES
ORDER BY annual_sal DESC;
-- 実行結果例：
-- LAST_NAME   ANNUAL_SAL
-- ----------  ----------
-- King            288000
-- Kochhar         204000
-- De Haan         204000
-- （別名 annual_sal の降順で並ぶ）
試験のポイント： NULL は昇順ソートではデフォルトで最後（NULLS LAST）、降順ソートではデフォルトで最初（NULLS FIRST）に表示されます。ORDER BY は SELECT リストにない列でもソートできます（DISTINCT 使用時を除く）。

OFFSETFETCHROWNUM置換変数DEFINEVERIFY

OFFSET / FETCH（行制限）

ORDER BY と組み合わせて、先頭から何行スキップし、何行取得するかを指定します。

-- 給与の高い順に、上位5件を取得
SELECT EMPLOYEE_ID, LAST_NAME, SALARY
FROM   EMPLOYEES
ORDER BY SALARY DESC
FETCH FIRST 5 ROWS ONLY;
-- 実行結果例：
-- EMPLOYEE_ID  LAST_NAME   SALARY
-- -----------  ----------  ------
--         100  King         24000
--         101  Kochhar      17000
--         102  De Haan      17000
--         145  Russell      14000
--         146  Partners     13500
-- （給与上位5件のみ返される）

-- 6〜10位を取得（5行スキップして5行取得）
SELECT EMPLOYEE_ID, LAST_NAME, SALARY
FROM   EMPLOYEES
ORDER BY SALARY DESC
OFFSET 5 ROWS FETCH NEXT 5 ROWS ONLY;
-- 実行結果例：
-- EMPLOYEE_ID  LAST_NAME   SALARY
-- -----------  ----------  ------
--         201  Hartstein    13000
--         205  Higgins      12008
--         108  Greenberg    12008
--         168  Ozer         11500
--         174  Abel         11000
-- （給与順の6位〜10位の5件が返される）

ROWNUM（疑似列）

-- 先頭10行（取得順）
SELECT *
FROM   EMPLOYEES
WHERE  ROWNUM <= 10;
-- 実行結果例：
-- EMPLOYEE_ID  LAST_NAME   SALARY  ...
-- -----------  ----------  ------
--         100  King         24000
--         101  Kochhar      17000
--         102  De Haan      17000
-- （テーブルの格納順で先頭10行が返される。ORDER BY を使わないと順序は不定）

置換変数（SQL*Plus系）

実行時に値を入力させる変数です。学習・検証で使われます。

-- & で単発置換
SELECT LAST_NAME, SALARY
FROM   EMPLOYEES
WHERE  DEPARTMENT_ID = &dept_id;

-- DEFINE で固定
DEFINE dept_id = 50
SELECT LAST_NAME FROM EMPLOYEES WHERE DEPARTMENT_ID = &dept_id;

-- VERIFY ON/OFF（置換前後の表示）
SET VERIFY ON
試験のポイント： 行制限は ORDER BY とセットで使わないと結果の順序が不定になります。ROWNUM は ORDER BY より前に付与されるため、上位N件抽出で誤用しやすいです。置換変数（DEFINE/VERIFY）は SQL*Plus 系の操作問題で問われることがあります。
