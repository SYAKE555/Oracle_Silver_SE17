# Oracle DBA Silver SQL 教科書 欠点指摘レポート（Ver 3.0着手前）

## 1. 既存版（Ver 2.0）に対する欠点指摘（厳密）

### 1-1. 解説の薄さ（情報密度不足）
1. 章ごとの説明が短く、定義・役割・原理・制限の深掘りが不均一。
2. 同一章内で「基本構文」はあるが、例外条件や境界条件が不足。
3. SQLの論理処理順はあるが、実行計画・性能観点への接続が弱い。
4. JOIN章で結合条件の誤りパターン（重複増殖・欠損行）の検証手順が不足。
5. 副問合せ章で `IN` / `EXISTS` / `NOT IN` / `NOT EXISTS` の使い分け基準が不足。
6. 集合演算子章で型グループ一致、列数一致の失敗例が不足。
7. DML章で同時実行（ロック・待機・競合）に関する実務説明が不足。
8. DDL章で制約設計の移行手順（既存データ補正→制約追加）が不十分。
9. 権限章でロール設計の粒度（職務別/環境別）例が不足。
10. 辞書ビュー章で障害初動テンプレSQLが限定的。
11. 日時章でタイムゾーン運用方針（保存TZ・表示TZ・監査TZ）の設計指針が薄い。
12. 試験対策として、引っかけ論点の網羅度が章間でばらつく。
13. 「なぜその構文が必要か」の業務起点説明が一部章で弱い。
14. `NULL` と3値論理（TRUE/FALSE/UNKNOWN）の因果説明が不足。
15. 暗黙の型変換による不具合例（NLS依存）の再現例が不足。
16. `MERGE` の投入元重複・更新条件競合の注意が薄い。
17. `SEQUENCE` の欠番仕様と業務番号の分離設計が短い。
18. `ORDER BY` 未指定時の非決定性の説明はあるが、再現実験が不足。
19. `GROUP BY` の粒度定義とKPI不一致の関係説明が浅い。
20. 「試験で解ける」から「実務で事故を起こさない」への橋渡しが不足。

### 1-2. 初学者配慮不足
21. 用語が先に出て後で説明される箇所があり、学習負荷が高い。
22. 用語注釈が章近傍に常設されておらず、往復参照が必要。
23. 章内の理解確認（チェック問題）が不足。
24. 誤答しやすいパターン（誤SQL）と正SQLの対比が少ない。
25. 「業務で依頼される言葉」からSQLへ落とし込む導線が薄い。
26. 画面・帳票・バッチなど利用シーン別の説明が不足。
27. 初学者向けに処理順を固定化する反復設計が不足。
28. 表示形式は改善済みだが、章内ナビ（前後章リンク）が不足。

### 1-3. 学習ノイズ（メタ情報残留）
29. 学習者に不要な運用背景・制作都合の文言が混在し得る。
30. 教材本文に「運用上の事情」を示す記述が残ると集中を阻害。
31. 学習画面には目的外情報（作成経緯・運用注記）を排除すべき。

### 1-4. 品証観点（構造品質）
32. 章ごとの品質5項目（定義/役割/原理/制限/急所）の粒度が揃っていない。
33. 同一テーマで実務例の深さが章ごとに不均等。
34. エラー条件の列挙はあるが、回避手順のテンプレ化が不足。
35. 学習完了判定（何ができれば合格水準か）の定義が弱い。
36. 章間依存（この章が分からないと次章で詰まる）マップが不足。

## 2. Ver 3.0 での是正方針（実装要求）
1. 全16章すべてを「定義・役割・動作原理・制限事項・試験/実務の急所」の固定テンプレートで統一。
2. 各章に「実務ケース」「誤り例」「正解例」「チェック項目」を常設。
3. 各章内に用語注釈ボックス（NULL、一意、暗黙変換、相関副問合せなど）を配置。
4. 目次サイドバーを固定表示し、長文スクロール負担を低減。
5. 各章末にトップ復帰リンクを配置。
6. SQLコードを高コントラストのライトテーマで色分け。
7. 図解（処理順、JOIN比較、更新手順、権限モデル）をHTML/CSSのみで実装。
8. 試験ひっかけポイントを章内に明示し、実務回避策とセットで提示。

## 3. バージョン管理手順（厳守）
1. 既存の現行版ファイルを `textbooks/old/` に退避する。
2. 退避時は必ずファイル名に版番号を含める。
   - 例: `textbooks/old/Ver_2_0_Oracle_DBA_Silver_SQL_Textbook.html`
3. 新版はルートに新規作成する。
   - 例: `textbooks/Ver_3_0_Oracle_DBA_Silver_SQL_Textbook.html`
4. 変更履歴は必ず `.md` で保存する。
   - 例: `docs/Ver_3_0_Oracle_DBA_Silver_SQL_ChangeLog.md`
5. インデックスや参照ガイド（`textbooks/index.html`、`SETUP_GUIDE.md`、`docs/location_map.md`）のリンクを新バージョンへ更新する。
