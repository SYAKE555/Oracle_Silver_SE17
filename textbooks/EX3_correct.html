日付演算と月数計算4問

DATE 型の差は日数で返る。月単位なら MONTHS_BETWEEN、月加算なら ADD_MONTHS を使う。年数を 365 日換算で書くと境界条件を外しやすい。

第1回 模擬試験 / 問16 / 正答 C / 自己回答 -
問題文
NUMBER型のITEM_IDと、DATE型のMADE_DATE（製造年月日）を含むITEM表があります。
製造年月日から2か月後の月末の日付を表示したい場合、実行するSQLを選択してください。
(1)		A.　SELECT ITEM_ID, LAST_DAY(ADD_MONTHS(MADE_DATE, 2),1) FROM ITEM;
(2)		B.　SELECT ITEM_ID, NEXT_DAY(ADD_MONTHS(MADE_DATE, 2),1) FROM ITEM;
(3)		C.　SELECT ITEM_ID, LAST_DAY(ADD_MONTHS(MADE_DATE, 2)) FROM ITEM;
(4)		D.　SELECT ITEM_ID, LAST_DAY (MONTHS_BETWEEN (MADE_DATE, SYSDATE)) FROM ITEM;
なぜそうなるか

この問題の論点は「日付演算と月数計算」です。DATE 型の差は日数で返る。月単位なら MONTHS_BETWEEN、月加算なら ADD_MONTHS を使う。年数を 365 日換算で書くと境界条件を外しやすい。 この設問では正答 C「SELECT ITEM_ID, LAST_DAY(ADD_MONTHS(MADE_DATE, 2)) FROM…」 を選べており、論点自体は取れています。

叩き直しポイント
  • 日数差は date1 - date2、月差は MONTHS_BETWEEN(date1, date2)。
  • nか月後・前は ADD_MONTHS(date, n) で書く。
  • 条件式では『過去16か月以内』のような日本語を数式に言い換えてから書く。

TO_CHAR・TO_NUMBER・TO_DATE の書式変換3問

文字列として保持された数値や日付を演算するには、まず TO_NUMBER や TO_DATE で型変換し、その後に TO_CHAR で表示形式を整える。書式モデルが一致しなければ失敗する。

第1回 模擬試験 / 問19 / 正答 A.B / 自己回答 -
問題文
SHOHIN 表では、PRODUCTION_DATE列はDATE型で、デフォルト日付形式はDD-MON-RRです。
SQL文についてエラーとならないものはどれですか。（2つ選択）
(1)		A.　SELECT TO_CHAR(PRODUCTION_DATE,'YYYY-MM-DD') FROM SHOHIN
(2)		B.　SELECT TO_DATE(TO_CHAR(PRODUCTION_DATE,'RR-MM-DD'),'RR-MM-DD') FROM SHOHIN
(3)		C.　SELECT TO_NUMBER(PRODUCTION_DATE) * 3 FROM SHOHIN
(4)		D.　SELECT TO_DATE(PRODUCTION_DATE * 5) FROM SHOHIN
(5)		E.　SELECT TO_NUMBER(PRODUCTION_DATE) FROM SHOHIN
なぜそうなるか

この問題の論点は「TO_CHAR・TO_NUMBER・TO_DATE の書式変換」です。文字列として保持された数値や日付を演算するには、まず TO_NUMBER や TO_DATE で型変換し、その後に TO_CHAR で表示形式を整える。書式モデルが一致しなければ失敗する。 この設問では正答 A「SELECT TO_CHAR(PRODUCTION_DATE,'YYYY-MM-DD') FROM SHOHIN」 / B「SELECT TO_DATE(TO_CHAR(PRODUCTION_DATE,'RR-MM-DD'),'RR-…」 を選べており、論点自体は取れています。

維持ポイント

自己回答の記録はありませんが、正答の論点を固定し直して再現性を上げます。

叩き直しポイント
  • 演算前に元の型へ戻し、表示直前に TO_CHAR で整形する。
  • 書式モデルの桁数、カンマ、小数点位置まで確認する。
  • TO_CHAR は表示、TO_NUMBER/TO_DATE は演算準備と役割分担で覚える。

ROUND・TRUNC・FLOOR などの数値関数1問

ROUND は四捨五入、TRUNC は切り捨て、FLOOR は指定値以下の最大整数、CEIL は指定値以上の最小整数を返す。関数ごとの戻り値を正確に区別する必要がある。

問題文

(1)		34
(2)		35
(3)		345
(4)		350
(5)		345.1
(6)		345.2
なぜそうなるか

この問題の論点は「ROUND・TRUNC・FLOOR などの数値関数」です。ROUND は四捨五入、TRUNC は切り捨て、FLOOR は指定値以下の最大整数、CEIL は指定値以上の最小整数を返す。関数ごとの戻り値を正確に区別する必要がある。 この設問では正答 3「345」 を選べており、論点自体は取れています。

維持ポイント

自己回答の記録はありませんが、正答の論点を固定し直して再現性を上げます。

叩き直しポイント
  • ROUND=四捨五入、TRUNC=切り落とし、FLOOR/CEIL=整数方向と覚える。
  • 小数点桁数指定があるときは第何位を見るのかを書き出す。
  • 日付に対する ROUND/TRUNC も使えることを別で覚える。

SUBSTR・INSTR・TRIM・REPLACE の使い分け1問

文字列の一部抽出では、位置取得に INSTR、切り出しに SUBSTR、不要部分の削除に TRIM、置換に REPLACE を使い分ける。空白位置の +1 を忘れると全体がずれる。
