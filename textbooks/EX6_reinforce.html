WHERE と HAVING4問

WHERE は集計前の行条件、HAVING は集計後のグループ条件である。集計関数を WHERE に直接書くとエラーになる。

論点の定義

集計問題では、行条件は WHERE、グループ条件は HAVING、集計関数以外の列は GROUP BY に含める、という基本規則を守る必要がある。

句の並び順（Oracle 正式構文）
SELECT グループ列, 集計関数(列) -- 集計結果 FROM 表 WHERE 行条件 -- ← 集計“前”。集計関数は書けない GROUP BY グループ化列 -- SELECT の非集計列はすべてここに含める HAVING 集計条件 -- ← 集計“後”。COUNT(*) 等はここに書く ORDER BY 集計列 / 位置番号 -- COUNT(*) は全行、COUNT(列) は NULL を除く。SUM/AVG/MIN/MAX は NULL を無視。
この論点の基本形
SELECT department_id, COUNT(*)
FROM   employees
WHERE  salary IS NOT NULL
GROUP  BY department_id
HAVING COUNT(*) >= 2;
成立条件
  • WHERE は集計前、HAVING は集計後に適用される。
  • COUNT(*) は全行、COUNT(col) は NULL を除く行数を返す。
  • SELECT に出す非集計列は GROUP BY にすべて含める。
判定手順
  1. 条件が行単位かグループ単位かを最初に判定する。
  2. 次に SELECT 列と GROUP BY 列の整合を確認する。
  3. NULL を含む列では COUNT(*) と COUNT(col) の違いを明示的に追う。
失点しやすい点: COUNT や AVG 条件を WHERE に置いてしまい、GROUP BY 後の条件だと気付けないことが多い。

解く順序
  • 条件が行単位かグループ単位かを最初に判定する。
  • 次に SELECT 列と GROUP BY 列の整合を確認する。
  • NULL を含む列では COUNT(*) と COUNT(col) の違いを明示的に追う。
