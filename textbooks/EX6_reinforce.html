(2)		B.　SELECT SUM(ITEM_TYPE1+ITEM_TYPE2),ITEM_NAME FROM ITEM WHERE ITEM_NAME LIKE 'R%';

問題文（抽出）
図のような表があります。

選択肢（抽出）
A

B

C
SELECT SUM(DISTINCT ITEM_TYPE1), MIN(ITEM_TYPE1) FROM ITEM WHERE ITEM_NAME LIKE 'R%';
D
SELECT AVG(ITEM_PRICE) FROM ITEM WHERE AVG(ITEM_PRICE) >= 500 GROUP BY ITEM_ID;
なぜそうなるか

この問題の論点は「WHERE と HAVING」です。WHERE は集計前の行条件、HAVING は集計後のグループ条件である。集計関数を WHERE に直接書くとエラーになる。 したがって正答は A「SELECT SUM(ITEM_TYPE1+ITEM_TYPE2) FROM ITEM WHERE ITEM_…」 / C「SELECT SUM(DISTINCT ITEM_TYPE1), MIN(ITEM_TYPE1) FROM I…」 になります。

今回の誤り

自己回答は A「SELECT SUM(ITEM_TYPE1+ITEM_TYPE2) FROM ITEM WHERE ITEM_…」 / B「SELECT SUM(ITEM_TYPE1+ITEM_TYPE2),ITEM_NAME FROM ITEM W…」 でした。一部は当たっていますが、B「SELECT SUM(ITEM_TYPE1+ITEM_TYPE2),ITEM_NAME FROM ITEM W…」 に引っ張られて取りこぼしています。COUNT や AVG 条件を WHERE に置いてしまい、GROUP BY 後の条件だと気付けないことが多い。

叩き直しポイント
  • 行条件は WHERE、集計結果条件は HAVING と固定する。
  • SELECT の論理処理順を FROM→WHERE→GROUP BY→HAVING で覚える。
  • HAVING が必要かどうかは『集計後に絞るか』で判断する。

COUNT・AVG と NULL2問

COUNT(*) は行数、COUNT(col) は NULL を除く列数、AVG(col) は NULL を平均計算から除外する。集計関数ごとに NULL の扱いが異なる。

第2回 模擬試験 / 問23 / 正答 AC / 自己回答 AB
記録原文（省略なし）
以下のSQLで正常に実行されるものはどれでしょうか。（2つ選択）

(1)		A.　SELECT ITEM_ID,MADE_DATE,AVG(ITEM_PRICE) FROM ITEM GROUP BY ITEM_ID,MADE_DATE;
(2)		B.　SELECT ITEM_ID,MADE_DATE,SUM(ITEM_PRICE) FROM ITEM GROUP BY ITEM_ID;
(3)		C.　SELECT MIN(AVG(ITEM_PRICE)) FROM ITEM GROUP BY ITEM_ID;
(4)		D.　SELECT ITEM_ID,MAX(AVG(ITEM_PRICE)) FROM ITEM GROUP BY ITEM_ID;
問題文（抽出）
以下のSQLで正常に実行されるものはどれでしょうか。（2つ選択）
選択肢（抽出）
A
SELECT ITEM_ID,MADE_DATE,AVG(ITEM_PRICE) FROM ITEM GROUP BY ITEM_ID,MADE_DATE;
B
SELECT ITEM_ID,MADE_DATE,SUM(ITEM_PRICE) FROM ITEM GROUP BY ITEM_ID;
C
SELECT MIN(AVG(ITEM_PRICE)) FROM ITEM GROUP BY ITEM_ID;
D
SELECT ITEM_ID,MAX(AVG(ITEM_PRICE)) FROM ITEM GROUP BY ITEM_ID;
なぜそうなるか

この問題の論点は「COUNT・AVG と NULL」です。COUNT(*) は行数、COUNT(col) は NULL を除く列数、AVG(col) は NULL を平均計算から除外する。集計関数ごとに NULL の扱いが異なる。 したがって正答は A「SELECT ITEM_ID,MADE_DATE,AVG(ITEM_PRICE) FROM ITEM GROU…」 / C「SELECT MIN(AVG(ITEM_PRICE)) FROM ITEM GROUP BY ITEM_ID;」 になります。

今回の誤り

自己回答は A「SELECT ITEM_ID,MADE_DATE,AVG(ITEM_PRICE) FROM ITEM GROU…」 / B「SELECT ITEM_ID,MADE_DATE,SUM(ITEM_PRICE) FROM ITEM GROU…」 でした。一部は当たっていますが、B「SELECT ITEM_ID,MADE_DATE,SUM(ITEM_PRICE) FROM ITEM GROU…」 に引っ張られて取りこぼしています。COUNT(*) と COUNT(col) を同一視し、AVG の分母に NULL 行まで含めて考えやすい。

叩き直しポイント
  • COUNT(*) は全行、COUNT(col) は NULL 除外を声に出して確認する。
  • AVG(col)=SUM(col)/COUNT(col) に近い考え方で整理する。
  • NULL を含む列の集計問題は分母を必ず確認する。
