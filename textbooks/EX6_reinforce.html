グループ関数・集計
元ドメイン: D4 ／ 優先度: 要復習

D4グループ関数・集計要復習

模試で落とした典型ミス

  • HAVING と WHERE を混同。正：WHERE は行フィルタ・集計前 / HAVING は集計後・グループフィルタ。
  • SELECT に集計関数以外の列を含めたのに GROUP BY に入れ忘れて ORA-00979。
  • COUNT(*) と COUNT(col) の差：COUNT(*)は NULL も数える、COUNT(col)は col が NULL の行を除外。

必修ルール

  • SELECT 列の規則：集計関数以外のすべての列は GROUP BY に列挙が必須。
  • 集計関数は NULL を無視。ただし COUNT(*) だけは NULL 行も数える。
  • HAVING はグループ関数条件、WHERE は行条件。HAVING は GROUP BY 省略時も書けるが、書けるのは集計関数条件のみ。
  • AVG(col) ≠ SUM(col)/COUNT(*) （NULL の扱いが違う）。AVG(col) は NULL を分母にも含めない。
  • ROLLUP(a,b)：(a,b)／(a)／() の小計行を追加。CUBE(a,b) は全組合せ。

構文・語彙チェックリスト

句対象集計関数使用
WHERE行不可
GROUP BY集計の単位不可（式は可）
HAVINGグループ可
ORDER BY最終結果可

ミニ演習（3問）

Q1. SELECT dept, AVG(sal) FROM emp GROUP BY dept HAVING AVG(sal) > 5000;を WHERE で書けるか？
A. 書けない。集計結果でのフィルタは HAVING のみ。
Q2. emp(10行、うち comm が NULL＝4行)、AVG(comm)の分母は？
A. 6（NULL は無視）。
Q3. GROUP BY なしで HAVING を付けると？
A. 全行を1グループとみなす。SUM(sal) > 10000 のように書ける。
