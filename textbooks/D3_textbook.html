D3: 単一行関数

Oracle Database SQL (1Z0-071) 対策
1行ずつ処理する単一行関数を学びます。
文字列関数、数値関数、日付関数、NULL関数と条件式を扱います。
コマンド覚え方リファレンス

UPPER 大文字に変換 「アッパー＝上」→文字を全部「大文字（上位）」にする 大文字統一・大文字小文字を無視した検索 使う（WHERE UPPER(列) = UPPER(:入力値)） UPPER/LOWER との組み合わせ・WHERE句での使用
LOWER 小文字に変換 「ロウアー＝下」→文字を全部「小文字（下位）」にする 小文字統一・比較前の正規化 使う UPPER との使い分け・結果の確認
INITCAP 先頭だけ大文字、残りは小文字 「イニシャル＋キャップ」→頭文字（Initial）だけ帽子（Cap）をかぶせる 名前の表示形式を整える 条件付き（表示用） UPPER/LOWER/INITCAP の動作の違い
LENGTH 文字列の長さを返す 「レングス＝長さ」→文字数をカウント 文字数チェック・バリデーション 使う マルチバイト文字の扱い・NULL の場合の戻り値
SUBSTR 部分文字列を取り出す 「サブ ストリング＝部分文字列」→開始位置と長さで切り出す コードの一部抽出・文字列加工 使う 開始位置が1始まり・負の値で末尾から・長さ省略で末尾まで
INSTR 文字列の位置を返す 「イン ストリング＝文字列の中の位置」→見つからなければ0を返す 特定文字の存在確認・位置取得 条件付き 見つからない場合は NULL でなく 0 を返す点
LPAD / RPAD 左/右を指定文字で埋める 「L＝Left（左）、R＝Right（右）、Pad＝埋める」→桁合わせに使う ゼロ埋め・固定長フォーマット 条件付き（帳票・整形時） LPAD('42', 5, '0') → '00042' の動作確認
TRIM 前後の空白や指定文字を除去 「トリム＝刈り込む」→前後の余分な文字を除去 入力データのクレンジング 使う LEADING / TRAILING / BOTH オプション
REPLACE 文字列を置換する 「リプレイス＝取り替える」→指定文字列を別の文字列に変換 文字列の置換・マスキング 使う 置換文字列を省略するとその文字を削除
ROUND（数値） 四捨五入 「ラウンド＝丸める」→指定桁で四捨五入 金額・数量の丸め処理 使う 第2引数の桁数（正・0・負）の動作
TRUNC（数値） 切り捨て 「トランケート＝切り詰める」→指定桁以下を切り捨て（四捨五入しない） 小数点以下の切り捨て 使う ROUND との違い（切り捨て vs 四捨五入）
MOD 余りを返す 「モジュロ＝割り算の余り」→MOD(10, 3) = 1 偶数奇数判定・周期処理 条件付き MOD(m, n) の結果・負の値の扱い
SYSDATE 現在の日時を返す 「システム デート＝システムの日時」→サーバーの現在時刻 現在日時の取得・日付計算の起点 使う（最頻出） DUAL テーブルとの組み合わせ・日付の加減算
ADD_MONTHS 指定月数を加算した日付 「アッド マンス＝月を足す」→ADD_MONTHS(日付, 3) で3ヶ月後 期限日・有効期限の計算 使う 月末日処理の動作（月末日に加算すると次の月末になる）
MONTHS_BETWEEN 2つの日付の間の月数 「マンス ビトウィーン＝月の間隔」→小数になることがある 勤続年数・経過月数の計算 使う 結果が小数になる場合・引数の順序（大きい日付を先に）
TO_CHAR 日付/数値を文字列に変換 「トゥ チャー＝文字に変換」→書式を指定して文字列へ 日付の表示形式変換・数値フォーマット 使う（最頻出） 日付フォーマット文字列（YYYY/MM/DD/HH24/MI/SS）
TO_DATE 文字列を日付型に変換 「トゥ デート＝日付に変換」→書式を指定して DATE 型へ 文字列の日付への変換・日付比較 使う フォーマット指定の必要性・デフォルト書式との違い
TO_NUMBER 文字列を数値に変換 「トゥ ナンバー＝数値に変換」→'123' → 123 文字列数値の計算への利用 条件付き 変換できない文字列が含まれるとエラー
NVL NULLなら代替値を返す 「ヌル バリュー＝NULL の値を置き換える」→NVL(列, 0) でNULLを0に NULL の置き換え・集計前処理 使う（最頻出） NVL と NVL2 の引数の違い・データ型一致の制約
NVL2 NULLか否かで2種類の値を返す 「NVL の2番目」→NULL でない場合と NULL の場合で別々の値 NULL/非NULLで異なる計算をする 使う NVL2(expr, notnull値, null値) の引数順序
NULLIF 2値が等しければNULLを返す 「ヌル イフ＝等しければNULL」→NULLIF(a, b): a=b なら NULL、違えば a ゼロ除算防止・特定値をNULLに変換 条件付き NULLIF の戻り値のパターン・NVL との組み合わせ
COALESCE 最初の非NULL値を返す 「コウアレス＝合体する」→複数引数の中から最初のNULLでない値を選ぶ 優先順位付きのNULL置換 使う（NVLより汎用的） NVL との違い（引数が複数・標準SQL準拠）
CASE 条件分岐で値を返す 「ケース＝場合」→WHEN〜THEN〜ELSE で条件ごとに異なる値 データの分類・ラベル付け・条件付き集計 使う（標準SQL） 単純CASE vs 検索CASE・ELSE省略時はNULL・DECODE との比較
略称・用語定義
D3 で扱う単一行関数は略称ではなく関数名そのものです。
各関数の正式な意味は上記のコマンド覚え方リファレンスを参照してください。
以下は関連する分類用語の定義です。
用語 正式・関連名称 意味
単一行関数 Single-Row Function 1行ごとに処理し、各行に対して1つの値を返す関数。
文字列・数値・日付・変換・NULL関数などが含まれる
グループ関数 Group Function / Aggregate Function 複数行をまとめて1つの値を返す関数（COUNT, SUM, AVG など）。
単一行関数とは異なる

精度は秒まで
TIMESTAMP 型 Oracle TIMESTAMP Type DATE 型より精度の高い日付時刻型。
小数秒（ナノ秒まで）を保持できる
NLS National Language Support Oracleの多言語サポート機能。

主要な文字列関数

関数構文説明
UPPERUPPER(str)大文字に変換
LOWERLOWER(str)小文字に変換
INITCAPINITCAP(str)先頭を大文字、残りを小文字
LENGTHLENGTH(str)文字数を返す
SUBSTRSUBSTR(str, start [,len])部分文字列を取り出す
INSTRINSTR(str, search)文字列の位置を返す
REPLACEREPLACE(str, from, to)文字を置換する
TRIMTRIM(str)前後の空白（または指定文字）を除去

SELECT UPPER('hello'),        -- HELLO
       LOWER('WORLD'),        -- world
       LENGTH('Oracle'),      -- 6
       SUBSTR('Oracle', 2, 3),-- rac
       INSTR('Oracle', 'a'),  -- 3
       REPLACE('abc', 'b', 'B'), -- aBc
       LPAD('42', 5, '0'),    -- 00042
       TRIM('  hello  ')      -- hello
FROM DUAL;
-- 実行結果例：
-- UPPER('HELLO')  LOWER('WORLD')  LENGTH('ORACLE')  SUBSTR('ORACLE',2,3)  INSTR('ORACLE','A')  REPLACE('ABC','B','B')  LPAD('42',5,'0')  TRIM('  HELLO  ')
-- --------------  --------------  ----------------  --------------------  -------------------  ----------------------  ----------------  -----------------
-- HELLO           world                          6  rac                                     3  aBc                     00042             hello
試験のポイント： SUBSTR の開始位置は 1 から始まります（0 を指定すると 1 と同じ動作）。
負の値を指定すると末尾からカウントします。
INSTR は見つからない場合 0 を返します（NULL ではない）。
練習問題
問題 1 #OSLV-D3-003

以下のSQL文の実行結果として正しいものはどれか。
```sql
SELECT SUBSTR('ABCDEFG', 3, 4) FROM DUAL;
```

  • A. BCD
  • B. CDEF
  • C. ABCD
  • D. BCDE
解答・解説を見る

正解: B. CDEF

正解は「CDEF」である。
SUBSTR(string, start, length)はstringのstart位置からlength文字を取り出す。
Oracleの文字列インデックスは1始まりである。
'ABCDEFG'の3番目の文字は'C'であり、そこから4文字（C, D, E, F）を取り出すと'CDEF'となる。
選択肢AはSUBSTR('ABCDEFG', 2, 3)の結果。
選択肢DはSUBSTR('ABCDEFG', 2, 4)の結果。
Oracle SQL Reference §SUBSTR参照。

数値関数
ROUNDTRUNCMODCEILFLOOR

主要な数値関数

関数構文説明
ROUNDROUND(n [,d])四捨五入。
d は小数点以下の桁数
TRUNCTRUNC(n [,d])切り捨て。
d は小数点以下の桁数
MODMOD(m, n)m を n で割った余り
CEILCEIL(n)n 以上の最小整数（切り上げ）
FLOORFLOOR(n)n 以下の最大整数（切り下げ）
SELECT ROUND(45.926, 2),   -- 45.93
       ROUND(45.926, 0),   -- 46
       ROUND(45.926, -1),  -- 50
       TRUNC(45.926, 2),   -- 45.92
       TRUNC(45.926, -1),  -- 40
       MOD(1600, 300),     -- 100
       CEIL(2.3),          -- 3
       FLOOR(2.7)          -- 2
FROM DUAL;
-- 実行結果例：
-- ROUND(45.926,2)  ROUND(45.926,0)  ROUND(45.926,-1)  TRUNC(45.926,2)  TRUNC(45.926,-1)  MOD(1600,300)  CEIL(2.3)  FLOOR(2.7)
-- ---------------  ---------------  ----------------  ---------------  ----------------  -------------  ---------  ----------
--           45.93               46                50            45.92                40            100          3           2
試験のポイント： ROUND と TRUNC の第2引数（桁数）は省略すると 0（整数）として扱われます。
負の値（例: -1）を指定すると十の位で丸めます。
MOD(m, n) は m が負の場合も使えます（結果の符号は m に依存）。
練習問題
問題 1 #OSLV-D3-001

以下のSQL文の実行結果として正しいものはどれか。
```sql
SELECT ROUND(45.926, 2), TRUNC(45.926, 2)
FROM DUAL;
```

  • A. 45.92 と 45.93
  • B. 45.93 と 45.92
  • C. 46 と 45
  • D. 45.926 と 45.926
解答・解説を見る

正解: B. 45.93 と 45.92

正解は「45.93 と 45.92」である。
ROUND(45.926, 2)は小数点第2位で四捨五入する。
第3位が6（5以上）なので第2位が繰り上がり 45.93 となる。
TRUNC(45.926, 2)は小数点第2位以下を切り捨てる（四捨五入しない）。
したがって 45.92 となる。
DUALは計算結果など値を返すためだけに使うOracleの仮想表。
選択肢Cは第0位での操作の結果であり誤り。
Oracle SQL Reference §ROUND, TRUNC参照。

日付関数
SYSDATEADD_MONTHSMONTHS_BETWEENTO_DATETO_CHARLAST_DAY

日付の基本

Oracle では日付型は DATE 型で、日付と時刻の両方を保持します。

-- 現在日時
SELECT SYSDATE FROM DUAL;
-- 実行結果例：
-- SYSDATE
-- -------------------
-- 2024-04-03 10:30:00

-- 日付の加減算（1日単位）
SELECT SYSDATE + 7 AS 1週間後,
       SYSDATE - 1 AS 昨日
FROM DUAL;
-- 実行結果例：
-- 1週間後              昨日
-- -------------------  -------------------
-- 2024-04-10 10:30:00  2024-04-02 10:30:00

主要な日付関数

関数説明例
ADD_MONTHS(d, n)日付に n ヶ月加算ADD_MONTHS(SYSDATE, 3)
MONTHS_BETWEEN(d1, d2)2日付間の月数MONTHS_BETWEEN(d1, d2)
LAST_DAY(d)月の末日を返すLAST_DAY(SYSDATE)
NEXT_DAY(d, day)次の指定曜日の日付NEXT_DAY(SYSDATE, 'MONDAY')
ROUND(d, fmt)日付の四捨五入ROUND(SYSDATE, 'MONTH')
TRUNC(d, fmt)日付の切り捨てTRUNC(SYSDATE, 'YEAR')

TO_CHAR / TO_DATE（変換関数）

-- 日付を文字列に変換
SELECT TO_CHAR(SYSDATE, 'YYYY-MM-DD HH24:MI:SS') FROM DUAL;
-- 実行結果例：
-- TO_CHAR(SYSDATE,'YYYY-MM-DD HH24:MI:SS')
-- ----------------------------------------
-- 2024-04-03 10:30:00

-- 文字列を日付に変換
SELECT TO_DATE('2024-01-15', 'YYYY-MM-DD') FROM DUAL;
-- 実行結果例：
-- TO_DATE('2024-01-15','YYYY-MM-DD')
-- ----------------------------------
-- 2024-01-15 00:00:00

-- 数値を文字列に変換
SELECT TO_CHAR(12345.67, '999,999.99') FROM DUAL;
-- 実行結果例：
-- TO_CHAR(12345.67,'999,999.99')
-- ------------------------------
--  12,345.67
試験のポイント： 日付同士の減算は日数（小数）を返します。
MONTHS_BETWEEN の結果は小数になることがあります（整数にするなら TRUNC や FLOOR を使用）。
TO_CHAR のフォーマット: YYYY=4桁年, MM=月, DD=日, HH24=24時間形式, MI=分, SS=秒。
NULL関数と条件式
NVLNVL2COALESCENULLIFDECODECASE

NULL を扱う関数

関数構文説明
NVLNVL(expr, alt)NULL なら alt を返す
NVL2NVL2(expr, notnull, null)NULL なら null_val、そうでなければ notnull_val を返す
COALESCECOALESCE(e1, e2, ...)NULL でない最初の値を返す
NULLIFNULLIF(e1, e2)e1 = e2 なら NULL、異なれば e1 を返す
-- NVL: コミッションが NULL なら 0 を使う
SELECT LAST_NAME,
       SALARY * (1 + NVL(COMMISSION_PCT, 0)) AS 合計給与
FROM   EMPLOYEES;
-- 実行結果例：
-- LAST_NAME   合計給与
-- ----------  --------
-- King           24000
-- Abel           14300
-- （COMMISSION_PCT が NULL の King は SALARY * 1 = 24000、
--   Abel は SALARY(11000) * (1 + 0.30) = 14300）

-- COALESCE: 最初の非 NULL 値
SELECT COALESCE(NULL, NULL, 'Hello', 'World') FROM DUAL; -- Hello
-- 実行結果例：
-- COALESCE(NULL,NULL,'Hello','World')
-- -----------------------------------
-- Hello

条件式（CASE / DECODE）

-- CASE 式（標準 SQL）
SELECT LAST_NAME,
       CASE JOB_ID
           WHEN 'IT_PROG' THEN 'IT部門'
           WHEN 'SA_REP'  THEN '営業部門'
           ELSE 'その他'
       END AS 部門名
FROM   EMPLOYEES;
-- 実行結果例：
-- LAST_NAME   部門名
-- ----------  --------
-- Hunold      IT部門
-- Abel        営業部門
-- King        その他
-- （JOB_ID に応じて部門名が割り当てられる。一致しない場合は ELSE の値）

-- DECODE（Oracle 独自）
SELECT LAST_NAME,
       DECODE(JOB_ID,
              'IT_PROG', 'IT部門',
              'SA_REP',  '営業部門',
              'その他') AS 部門名
FROM   EMPLOYEES;
-- 実行結果例：
-- LAST_NAME   部門名
-- ----------  --------
-- Hunold      IT部門
-- Abel        営業部門
-- King        その他
-- （CASE 式と同等の結果。DECODE は Oracle 独自構文）
試験のポイント： NVL と NVL2 は引数のデータ型が一致している必要があります。
COALESCE は標準 SQL で移植性が高いです。
DECODE は Oracle 独自です。
CASE 式の方が標準 SQL に準拠しています。
CASE 式には「単純 CASE（WHEN 値）」と「検索 CASE（WHEN 条件）」の2種類があります。
練習問題
問題 1 #OSLV-D3-002

以下のSQL文の実行結果として正しいものはどれか。
```sql
SELECT NVL2(commission_pct, salary * commission_pct, 0)
FROM employees
WHERE employee_id = 100;
```
employee_id=100 は commission_pct = NULL, salary = 24000 とする。

  • A. 24000
  • B. NULL
  • C. 0
  • D. エラーになる
解答・解説を見る

正解: C. 0

正解は「0」である。
NVL2(expr1, expr2, expr3)は expr1 がNULLでなければ expr2 を返し、NULLであれば expr3 を返す。
commission_pctがNULLのため、expr3である0が返される。
NVL(expr1, expr2)との違いは、NVLはNULLのとき代替値を返すだけだが、NVL2はNULLでない場合の式も指定できる点。
この例はNULLでない場合は歩合給計算、NULLの場合は0を返す典型的な使い方。
Oracle SQL Reference §NVL2参照。

問題 2 #OSLV-D3-004

以下のSQL文の実行結果として正しいものはどれか。
```sql
SELECT
CASE job_id
WHEN 'IT_PROG' THEN '開発'
WHEN 'SA_MAN' THEN '営業'
ELSE 'その他'
END AS job_type
FROM employees
WHERE employee_id = 200;
```
employee_id=200 の job_id = 'HR_REP' とする。

  • A. 開発
  • B. 営業
  • C. NULL
  • D. その他
解答・解説を見る

正解: D. その他

正解は「その他」である。
CASE式の単純CASE形式はWHEN節で指定した値と一致するかを順番に比較する。
job_id = 'HR_REP'は'IT_PROG'にも'SA_MAN'にも一致しないため、ELSEの'その他'が返される。
ELSE句がない場合、どのWHEN条件にも一致しないときNULLが返される。
CASE式はSELECT句・WHERE句・ORDER BY句などで使用できる。
Oracle SQL Reference §CASE式参照。
