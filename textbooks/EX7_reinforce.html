第1回 模擬試験 / 問48 / 正答 C.D.F / 自己回答 B.C.D
問題文
データ型に関して正しいのはどれでしょうか。（3つ選択）
選択肢
A
LONG型の最大サイズは1GBです。
B
TIMESTAMP型の列には、最小は秒の単位で値が格納されます。
C
VARCHAR2型の列に指定できる最小サイズは1バイトまたは1文字です。
D
CHAR型は固定長です。
E
BLOB型の列は、OSのファイルにバイナリデータを格納するために使用されます。
F
表ごとに使用できるLONG型は1つだけです。
なぜそうなるか

この問題の論点は「SQL 分類の基礎」です。DDL は定義変更、DML はデータ操作、DCL は権限制御、TCL はトランザクション制御である。各文をどこへ分類するかが基礎力になる。 したがって正答は C「VARCHAR2型の列に指定できる最小サイズは1バイトまたは1文字です。」 / D「CHAR型は固定長です。」 / F「表ごとに使用できるLONG型は1つだけです。」 になります。

今回の誤り

自己回答は B「TIMESTAMP型の列には、最小は秒の単位で値が格納されます。」 / C「VARCHAR2型の列に指定できる最小サイズは1バイトまたは1文字です。」 / D「CHAR型は固定長です。」 でした。一部は当たっていますが、B「TIMESTAMP型の列には、最小は秒の単位で値が格納されます。」 に引っ張られて取りこぼしています。TRUNCATE や COMMIT の分類が曖昧で、設問を読む前に迷いが生じやすい。

叩き直しポイント
  • CREATE/ALTER/DROP/TRUNCATE は DDL。
  • INSERT/UPDATE/DELETE/MERGE は DML。
  • COMMIT/ROLLBACK/SAVEPOINT は TCL、GRANT/REVOKE は DCL。

選択肢
A
SUM関数は、文字データ型の列で使用できます。
B
集計関数は、最大2レベルまでネストできます。
C
AVG関数は、文字データ型の列で使用できます。
D
MAX関数は、NULL値は指定できません。
E
MIN関数は、BINARYデータ型は指定できません。
なぜそうなるか

この問題の論点は「主キー・外部キー・一意キーと NULL」です。主キーは NOT NULL かつ一意、外部キーは NULL 可、一意キーも NULL を許せる。キー制約ごとの NULL 許容差が基本である。 したがって正答は B「集計関数は、最大2レベルまでネストできます。」 になります。

今回の誤り

自己回答は D「MAX関数は、NULL値は指定できません。」 でした。主キーと一意キーを同じ扱いで覚えたり、外部キーが必ず値を持つと考えやすい。 正答との差は、条件の向き、句の置き場所、またはオブジェクトの性質を正確に読み切れていない点にあります。

叩き直しポイント
  • PK は NULL 不可、UK と FK は NULL 可で分ける。
  • NULL は『未定』であって参照違反ではないことを理解する。
  • キー問題では制約の目的を日本語で言い換える。
