D4: グループ関数と集計

Oracle Database SQL (1Z0-071) 対策
複数行をまとめて集計するグループ関数と、GROUP BY / HAVING を使ったグループ集計を学びます。
コマンド覚え方リファレンス
コマンド/関数 意味（日本語） 覚え方（語呂合わせや連想） 主な用途 実務での使用 試験での出方（頻出パターン）
COUNT 行数を数える 「カウント＝数える」→COUNT(*) は全行、COUNT(列) はNULL除く 件数集計・存在確認 使う（最頻出） COUNT(*) vs COUNT(列) の NULL 扱いの違い
SUM 合計値を返す 「サム＝合計」→数値列のNULLを無視して合計 売上合計・給与総額の集計 使う NULL を含む列の SUM の動作
AVG 平均値を返す 「アベレージ＝平均」→NULLを除いた行で割る（分母も減る） 平均給与・平均点数の計算 使う NULL を含む AVG と NVL を使った全員平均の違い
MAX 最大値を返す 「マックス＝最大」→数値・文字・日付すべてに使える 最高給与・最新日付の取得 使う 文字列・日付型でも使用可能な点
MIN 最小値を返す 「ミニマム＝最小」→数値・文字・日付すべてに使える 最低給与・最古日付の取得 使う MAX との組み合わせ・NULL を無視する点
GROUP BY グループに分けて集計 「グループ バイ＝〜でグループ分け」→指定列の値が同じ行をまとめる 部署別・月別などの集計 使う（集計クエリの基本） SELECT 列は GROUP BY か集計関数のみ可（ORA-00979）
HAVING グループへの条件指定 「ハビング＝持っている条件」→グループ化後の結果を絞り込む 平均以上の部署を抽出など 使う WHERE との違い（行 vs グループ）・集計関数を条件に使える
DISTINCT（集計内） 重複を除いて集計 「ディスティンクト＝重複なし」→COUNT(DISTINCT 列) で種類数を数える ユニークな値の件数取得 条件付き（種類数が必要な場合） COUNT(*) / COUNT(列) / COUNT(DISTINCT 列) の違い
略称・用語定義
略称/用語 正式名称 意味
GROUP BY Group By Clause（グループ化句） 指定した列の値が同じ行をグループとしてまとめ、各グループに対して集計を行う句。
SELECT 句に書ける非集計列は GROUP BY に含める必要がある
HAVING Having Clause（グループ条件句） GROUP BY でグループ化した後の結果に対して条件を適用する句。
WHERE は行レベルの絞り込み、HAVING はグループレベルの絞り込みに使う
ORA-00979 Oracle Error 00979 「GROUP BY の式ではありません」というエラー。
SELECT 句に書いた列が GROUP BY にも集計関数にも含まれていない場合に発生する
集計関数 Aggregate Function / Group Function 複数行をまとめて1つの値を返す関数の総称。
COUNT / SUM / AVG / MAX / MIN などが該当する

グループ関数とは

グループ関数（集計関数）は複数の行をまとめて1つの結果を返す関数です。

関数説明NULL の扱い
COUNT(*)行数を返すNULL 行も含めてカウント
COUNT(列)指定列の非 NULL 件数NULL を無視
SUM(列)合計値NULL を無視
AVG(列)平均値NULL を無視（分母も減る）
MAX(列)最大値NULL を無視
MIN(列)最小値NULL を無視
SELECT COUNT(*) AS 総件数,
       COUNT(COMMISSION_PCT) AS コミッションあり件数,
       SUM(SALARY) AS 給与合計,
       AVG(SALARY) AS 給与平均,
       MAX(SALARY) AS 最高給与,
       MIN(SALARY) AS 最低給与
FROM   EMPLOYEES;
-- 実行結果例：
-- 総件数  コミッションあり件数  給与合計   給与平均              最高給与  最低給与
-- ------  --------------------  ---------  --------------------  --------  --------
--    107                    35     691400   6461.68224299...        24000      2100

DISTINCT との組み合わせ

-- 重複を除いた件数
SELECT COUNT(DISTINCT DEPARTMENT_ID) AS 部署数
FROM   EMPLOYEES;
-- 実行結果例：
-- 部署数
-- ------
--     11
-- （EMPLOYEES テーブルに存在する部署の種類数。NULL は除かれる）
試験のポイント： AVG(COMMISSION_PCT) は NULL を除いた平均です。
全員での平均を求めるなら AVG(NVL(COMMISSION_PCT, 0)) を使います。
COUNT(*) と COUNT(列) の違いは頻出です。
練習問題
問題 1 #OSLV-D4-001

以下のSQL文の実行結果として正しいものはどれか。
```sql
SELECT COUNT(*), COUNT(commission_pct), AVG(commission_pct)
FROM employees;
```
全107行のうち commission_pct が NULL でない行が35行、NULLの行が72行あるとする。

  • A. 107, 107, 全107行の平均値
  • B. 107, 35, NULL以外の35行の平均値
  • C. 35, 35, NULL以外の35行の平均値
  • D. 107, 35, 0
解答・解説を見る

正解: B. 107, 35, NULL以外の35行の平均値

正解は「107, 35, NULL以外の35行の平均値」である。
COUNT(*)はNULLを含む全行数を数えるので107。
COUNT(列名)はNULL以外の行数を数えるので35。
AVG(列名)もNULLを無視して計算するため、NULL以外の35行の合計÷35となる。
グループ関数（COUNT, SUM, AVG, MAX, MIN）はCOUNT(*)以外すべてNULLを無視する。
ただしCOUNT(*)のみNULLを含む全行を数える特別な動作をする。
Oracle SQL Reference §グループ関数参照。

問題 2 #OSLV-D4-002

以下のSQL文はエラーになる。
その理由として正しいものはどれか。
```sql
SELECT department_id, last_name, AVG(salary)
FROM employees
GROUP BY department_id;
```

  • A. AVG関数はGROUP BYと一緒に使えないため
  • B. last_nameがGROUP BY句にもグループ関数にも含まれていないため
  • C. department_idとlast_nameを同時にSELECTできないため
  • D. エラーにはならない
解答・解説を見る

正解: B. last_nameがGROUP BY句にもグループ関数にも含まれていないため

正解は「last_nameがGROUP BY句にもグループ関数にも含まれていないため」である。
GROUP BYを使う場合、SELECT句に書ける列は（1）GROUP BY句に含まれている列、または（2）グループ関数（AVG, COUNT等）で集計した列のみである。
last_nameはGROUP BY department_idに含まれておらず、グループ関数でも囲まれていないため、ORA-00979エラーが発生する。
department_idとAVG(salary)はルールを満たしているので問題ない。

問題 3 #OSLV-D4-003

以下のSQL文の実行結果として正しいものはどれか。
```sql
SELECT department_id, AVG(salary)
FROM employees
GROUP BY department_id
HAVING AVG(salary) > 8000
ORDER BY AVG(salary) DESC;
```

  • A. 全社員の中から給与が8000超の社員を部署ごとに集計して降順表示
  • B. HAVING句はWHERE句の代わりなのでWHERE AVG(salary) > 8000 と同じ
  • C. 部署ごとの平均給与を計算し、平均が8000超の部署のみを降順で表示する
  • D. エラーになる（HAVING句にはグループ関数を使えない）
解答・解説を見る

正解: C. 部署ごとの平均給与を計算し、平均が8000超の部署のみを降順で表示する

正解は「部署ごとの平均給与を計算し、平均が8000超の部署のみを降順で表示する」である。
SQL実行順序はFROM→WHERE→GROUP BY→HAVING→SELECT→ORDER BY。
HAVING句はGROUP BYでグループ化された後の結果を絞り込む。
選択肢AはHAVINGではなくWHEREを使った場合の説明で、個々の行を絞り込むもの。
選択肢BはWHERE句にはグループ関数は書けないので誤り。
HAVINGにはグループ関数の条件を書くことができる。

GROUP BY と HAVING
GROUP BYHAVINGSQL実行順序ORA-00979

GROUP BY の基本

GROUP BY でグループに分けてから集計します。

-- 部署ごとの給与合計
SELECT DEPARTMENT_ID,
       SUM(SALARY) AS 給与合計,
       COUNT(*) AS 人数
FROM   EMPLOYEES
GROUP BY DEPARTMENT_ID;
-- 実行結果例：
-- DEPARTMENT_ID  給与合計  人数
-- -------------  --------  ----
--            10      4400     1
--            20     19000     2
--            30     24900     6
--            40      6500     1
--            50    156400    45
--           （NULL）  7000     1
-- （部署ごとに給与合計と人数が集計される。NULL の部署も1グループとして扱われる）

HAVING 句

HAVING はグループに対する条件を指定します（WHERE はグループ前の行への条件）。

-- 平均給与が 8000 以上の部署
SELECT DEPARTMENT_ID,
       AVG(SALARY) AS 平均給与
FROM   EMPLOYEES
GROUP BY DEPARTMENT_ID
HAVING AVG(SALARY) >= 8000;
-- 実行結果例：
-- DEPARTMENT_ID  平均給与
-- -------------  --------
--            20   9500.00
--            90  19333.33
--           100   8601.33
--           110   10154.00
-- （全部署の中から平均給与が 8000 以上の部署のみ返される）

SQL の実行順序

順序句説明
1FROMテーブルの取得
2WHERE行の絞り込み
3GROUP BYグループ化
4HAVINGグループの絞り込み
5SELECT列の選択
6ORDER BYソート
試験のポイント（ORA-00979）： SELECT に記述した列は GROUP BY にも含める必要があります。
グループ関数以外の列が SELECT にあり、GROUP BY に含まれていない場合は ORA-00979 エラーになります。
WHERE にはグループ関数を使えません（HAVING を使う）。
