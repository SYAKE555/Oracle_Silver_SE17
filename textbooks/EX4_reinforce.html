DML・トランザクション
元ドメイン: D7 ／ 優先度: 優先

D7DML・トランザクション優先

🔥 模試で落とした典型ミス

  • ROLLBACK TO SAVEPOINT がロックまで解除すると誤認。正：SAVEPOINT 以降の変更を取り消すがロック解除はしない。SAVEPOINT 自体は残る。
  • UPDATE の SET リストで AND を区切り文字に使う選択肢を選ぶ。正：カンマ区切り。
  • INSERT ALL の WHEN 句に ELSE が使えないと誤認。正：ELSE 句あり。1行を複数表に挿入可能（INSERT FIRST は最初に合致した WHEN のみ）。
  • MERGE で UPDATE 側に WHERE 句が書けないと誤認。WHEN MATCHED THEN UPDATE SET ... WHERE ... が可能。DELETE も WHERE 付で可。

📌 必修ルール

  • COMMIT / ROLLBACK：COMMIT で確定・全SAVEPOINT消去、ROLLBACK で現在のトランザクション全破棄・全SAVEPOINT消去。
  • ROLLBACK TO SAVEPOINT s1：s1 以降の変更を破棄。s1 自体は残り、それより前の SAVEPOINT も残る。行ロックは維持される。
  • DDL の暗黙コミット：CREATE / ALTER / DROP / TRUNCATE / GRANT / REVOKE は自動的に COMMIT される。ROLLBACK できない。
  • TRUNCATE vs DELETE：TRUNCATE はDDL・高速・ログ小・ROLLBACK不可・トリガ起動しない・HWM リセット / DELETE はDML・行単位・ROLLBACK可・トリガ起動・HWMそのまま。
  • INSERT ALL（無条件）：全 INTO に全行を挿入。
  • INSERT ALL（条件付）：WHEN ～ THEN INTO、ELSE が使える。条件に合うすべての INTO に挿入。
  • INSERT FIRST：最初に合致した WHEN のみ実行。以降の WHEN はスキップ。
  • MERGE：USING 側は表・ビュー・サブクエリ。ON 条件で更新/挿入を分岐。MATCHED 側で UPDATE と DELETE を同時に記述可能。
  • SELECT FOR UPDATE：行ロックを取得。COMMIT / ROLLBACK までロックが続く。

✅ 構文・語彙チェックリスト

操作COMMIT要否ROLLBACK可否トリガ
INSERT / UPDATE / DELETE / MERGE明示必要可起動
TRUNCATE TABLE自動（DDL）不可起動しない

🎯 ミニ演習（3問）

Q1. INSERT ALL と INSERT FIRST の違いは？
A. ALL は条件に合う全 WHEN に挿入、FIRST は最初にヒットした WHEN のみ。
Q2. UPDATE 文で複数列を同時更新するときの区切りは？
A. カンマ。SET a=1, b=2。AND は不可。
Q3. ROLLBACK TO SAVEPOINT の後、行ロックはどうなる？
A. 維持される（解除されない）。完全な ROLLBACK や COMMIT で初めて解放。
