(4)		D.　副問合せはUPDATEで結合条件を持つことができないため、エラーとなります。
なぜそうなるか

この問題の論点は「UPDATE とサブクエリ」です。UPDATE の SET 句で相関サブクエリを使うと、更新対象行ごとにサブクエリが評価される。サブクエリが複数行を返せばエラーになる。 この設問では正答 B「正常に実行されますが、必要な更新が行われません。」 を選べており、論点自体は取れています。

維持ポイント

自己回答の記録はありませんが、正答の論点を固定し直して再現性を上げます。

叩き直しポイント
  • SET 句内で外側表の列を参照していたら相関サブクエリ。
  • 1行ごとに評価されることを前提に読む。
  • 単一行が保証できないなら結合 UPDATE など別案を考える。
