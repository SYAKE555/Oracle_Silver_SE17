D6: サブクエリ

Oracle Database SQL (1Z0-071) 対策
SELECT 文の中に別の SELECT 文を入れ子にするサブクエリの書き方と使いどころを学びます。

サブクエリとは

サブクエリは SELECT 文の中に入れ子にした別の SELECT 文です。内側のクエリ（サブクエリ）が先に実行され、その結果を外側のクエリが使います。

単一行サブクエリ

1行1列だけを返すサブクエリ。= や > などの比較演算子と組み合わせます。

-- Abel と同じ部署の従業員
SELECT LAST_NAME, DEPARTMENT_ID
FROM   EMPLOYEES
WHERE  DEPARTMENT_ID = (
    SELECT DEPARTMENT_ID
    FROM   EMPLOYEES
    WHERE  LAST_NAME = 'Abel'
);

-- 最低給与よりも多く稼ぐ従業員
SELECT LAST_NAME, SALARY
FROM   EMPLOYEES
WHERE  SALARY > (
    SELECT MIN(SALARY)
    FROM   EMPLOYEES
);

スカラーサブクエリ

SELECT リストや WHERE 句で1値を返すサブクエリです。

SELECT LAST_NAME,
       SALARY,
       (SELECT AVG(SALARY) FROM EMPLOYEES) AS 全体平均
FROM   EMPLOYEES;
試験のポイント： 単一行サブクエリが複数行を返すと ORA-01427 エラーになります。スカラーサブクエリが0行を返す場合は NULL が返ります。
練習問題
問題 1 #OSLV-D6-001

以下のSQL文の動作として正しいものはどれか。
```sql
SELECT last_name, salary
FROM employees
WHERE salary > (SELECT AVG(salary) FROM employees);
```

  • A. 全社員の平均給与より高い給与を受け取る社員の名前と給与を返す
  • B. 部署ごとの平均給与より高い給与を受け取る社員を返す
  • C. エラーになる（WHERE句にサブクエリは使えない）
  • D. サブクエリが複数行返す場合にエラーになる
解答・解説を見る

正解: A. 全社員の平均給与より高い給与を受け取る社員の名前と給与を返す

正解は「全社員の平均給与より高い給与を受け取る社員の名前と給与を返す」である。このサブクエリは単一行サブクエリ（AVGは1つの値を返す）であり、=, >, <, >=, <=などの単一行比較演算子と使用できる。外側のクエリはサブクエリが返した平均値と各行のsalaryを比較する。WHERE句にサブクエリは使用可能。サブクエリが複数行を返す可能性がある場合はIN, ANY, ALLなどの複数行演算子を使う必要がある。

問題 2 #OSLV-D6-002

以下のSQL文の動作として正しいものはどれか。
```sql
SELECT last_name, salary
FROM employees
WHERE salary = ANY (
SELECT MIN(salary)
FROM employees
GROUP BY department_id
);
```

  • A. 全部署の最低給与と一致する給与を持つ社員のみを返す
  • B. いずれかの部署の最低給与と一致する給与を持つ社員を返す
  • C. 最低給与が最も低い部署の社員のみを返す
  • D. エラーになる（= ANY は不正な構文）
解答・解説を見る

正解: B. いずれかの部署の最低給与と一致する給与を持つ社員を返す

正解は「いずれかの部署の最低給与と一致する給与を持つ社員を返す」である。= ANY は複数行サブクエリで使用し、「いずれかの値と等しい」という意味になる（INと同等の動作）。サブクエリは部署ごとの最低給与をリストで返す。外側のクエリはそのリスト内のいずれかの値とsalaryが一致する社員を返す。= ALLは「すべての値と等しい」、> ANYは「いずれかの値より大きい（最小値より大きい）」、> ALLは「すべての値より大きい（最大値より大きい）」を意味する。

問題 3 #OSLV-D6-003

以下のSQL文で EXISTS を使う効果として正しいものはどれか。
```sql
SELECT department_id, department_name
FROM departments d
WHERE EXISTS (
SELECT 1 FROM employees e
WHERE e.department_id = d.department_id
);
```

  • A. 全部署の社員数を返す
  • B. 社員が1名もいない部署のみを返す
  • C. 少なくとも1名の社員が所属する部署のみを返す
  • D. エラーになる（相関サブクエリのSELECTは * のみ使用可能）
解答・解説を見る

正解: C. 少なくとも1名の社員が所属する部署のみを返す

正解は「少なくとも1名の社員が所属する部署のみを返す（選択肢C）」である。EXISTSは相関サブクエリが1行以上の結果を返せばTRUE、0行ならFALSEとなる。SELECT 1（またはSELECT *）は実際の値ではなくEXISTSの存在チェックに使うため、列の内容は何でもよい。外側クエリのdをサブクエリ内で参照している（d.department_id）のが相関の部分。NOT EXISTSにすると社員が1名もいない部署を返す。

複数行サブクエリ
複数行サブクエリINANYALLNOT IN

複数行サブクエリ

複数行を返すサブクエリには IN, ANY, ALL などの演算子を使います。

演算子説明
INリストのどれかと等しい
NOT INリストのどれとも等しくない
ANY (SOME)リストの少なくとも1つと比較条件を満たす
ALLリストのすべての値と比較条件を満たす
-- 部署 20 または 50 のジョブ ID のいずれかに一致する従業員
SELECT LAST_NAME, JOB_ID
FROM   EMPLOYEES
WHERE  JOB_ID IN (
    SELECT JOB_ID
    FROM   EMPLOYEES
    WHERE  DEPARTMENT_ID IN (20, 50)
);

-- ANY: 部署 50 の誰かより給与が多い
SELECT LAST_NAME, SALARY
FROM   EMPLOYEES
WHERE  SALARY > ANY (
    SELECT SALARY
    FROM   EMPLOYEES
    WHERE  DEPARTMENT_ID = 50
);

-- ALL: 部署 50 の全員より給与が多い
SELECT LAST_NAME, SALARY
FROM   EMPLOYEES
WHERE  SALARY > ALL (
    SELECT SALARY
    FROM   EMPLOYEES
    WHERE  DEPARTMENT_ID = 50
);
試験のポイント： NOT IN のリストに NULL が含まれると、結果は0行になります（NULL との比較が不定のため）。> ANY は「最小値より大きい」、> ALL は「最大値より大きい」と覚えましょう。

集合演算子（UNION / INTERSECT / MINUS）
UNIONUNION ALLINTERSECTMINUS集合演算子

集合演算子の基本

複数の SELECT 結果を集合として結合・比較します。SELECT の列数とデータ型互換が必要です。

演算子説明
UNION重複を除去して結合
UNION ALL重複を保持して結合
INTERSECT共通部分のみ抽出
MINUS左にあり右にない行を抽出
-- 部署10と20の従業員IDを統合（重複除去）
SELECT EMPLOYEE_ID FROM EMPLOYEES WHERE DEPARTMENT_ID = 10
UNION
SELECT EMPLOYEE_ID FROM EMPLOYEES WHERE DEPARTMENT_ID = 20;

-- 重複を保持して統合
SELECT EMPLOYEE_ID FROM EMPLOYEES WHERE DEPARTMENT_ID = 10
UNION ALL
SELECT EMPLOYEE_ID FROM EMPLOYEES WHERE DEPARTMENT_ID = 20;

-- 共通する JOB_ID
SELECT JOB_ID FROM EMPLOYEES WHERE DEPARTMENT_ID = 10
INTERSECT
SELECT JOB_ID FROM EMPLOYEES WHERE DEPARTMENT_ID = 20;

-- 部署10にいて部署20にはいない従業員
SELECT EMPLOYEE_ID FROM EMPLOYEES WHERE DEPARTMENT_ID = 10
MINUS
SELECT EMPLOYEE_ID FROM EMPLOYEES WHERE DEPARTMENT_ID = 20;
試験のポイント： 重複排除が不要なら UNION ALL が高速です。ORDER BY は原則として最後の SELECT 全体に対して1回だけ指定します。
相関サブクエリとEXISTS
EXISTSNOT EXISTS相関サブクエリ相関

相関サブクエリ

外側のクエリの列を参照するサブクエリです。外側の行ごとに繰り返し実行されます。

-- 自分の部署の平均給与より高い従業員
SELECT o.LAST_NAME, o.SALARY, o.DEPARTMENT_ID
FROM   EMPLOYEES o
WHERE  o.SALARY > (
    SELECT AVG(i.SALARY)
    FROM   EMPLOYEES i
    WHERE  i.DEPARTMENT_ID = o.DEPARTMENT_ID
);

EXISTS / NOT EXISTS

EXISTS はサブクエリが1行以上返す場合に真になります。IN より効率的な場合があります。

-- 部下が存在する従業員（管理職）
SELECT e.LAST_NAME, e.EMPLOYEE_ID
FROM   EMPLOYEES e
WHERE  EXISTS (
    SELECT 1
    FROM   EMPLOYEES sub
    WHERE  sub.MANAGER_ID = e.EMPLOYEE_ID
);

-- 部下がいない従業員
SELECT e.LAST_NAME, e.EMPLOYEE_ID
FROM   EMPLOYEES e
WHERE  NOT EXISTS (
    SELECT 1
    FROM   EMPLOYEES sub
    WHERE  sub.MANAGER_ID = e.EMPLOYEE_ID
);
試験のポイント： EXISTS はサブクエリが行を返すかどうかだけを確認するため、SELECT リストは SELECT 1 や SELECT * でも問題ありません。NOT IN と NOT EXISTS は NULL の扱いが異なります。NOT IN は NULL が含まれると0行ですが、NOT EXISTS は NULL の影響を受けません。
